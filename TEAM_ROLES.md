## 2. Project Overview

The Stock Price Predictor is a Python-based machine learning application developed as part of the Artificial Intelligence Internship at Codec Technologies.

The application collects and processes historical stock market data, generates technical indicators, trains machine learning models, and evaluates their prediction performance.

The system provides an interactive Streamlit dashboard for stock data visualization, model evaluation, and prediction output.

### Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Plotly
- yfinance
- Pytest
- Git and GitHub

## 4. Team Collaboration and Workflow

The project follows a collaborative development workflow:

1. **Planning:** Define project requirements, objectives, and responsibilities.
2. **Data Analysis:** Examine stock market datasets and identify relevant features.
3. **Development:** Implement backend modules, machine learning models, and the Streamlit dashboard.
4. **Integration:** Connect data processing, model training, and frontend components.
5. **Testing:** Execute automated tests and verify application functionality.
6. **Documentation:** Prepare technical explanations, diagrams, screenshots, and the final internship report.

Although each member has a primary role, all five members participate in project discussions, integration, reviews, testing, and documentation.
